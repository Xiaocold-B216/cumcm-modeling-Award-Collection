# 问题对应与解题结构

- 年度：2024
- 赛题：C题《农作物的种植策略》
- 论文代码：C094
- 题名：基于随机优化的农作物种植策略模型

## 赛题任务

为54个地块/大棚和41种作物制定2024—2030年多季种植方案，处理滞销、价格折扣、风险和作物相关性。

- 确定性滞销/半价场景
- 销售量产量成本价格不确定性
- 替代互补和销量价格成本相关性

## 本文总体路线

建立线性种植规划并同时用求解器和贪心算法求解；不确定性通过蒙特卡洛和随机扰动评估，相关性部分用替代与软约束修正。
