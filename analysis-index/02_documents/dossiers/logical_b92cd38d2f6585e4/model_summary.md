# 模型与算法摘要

## 总体方法

从理想一维模型推广到鼓面三维刚体运动，利用欧拉刚体旋转定理和模拟退火优化协作策略，并讨论鼓面倾斜的全局纠偏。

## 模型与算法

- **一维常系数微分方程**（ode_model）：在水平拉绳假设下描述鼓和球的高度、速度。；证据页：4, 5。
- **动量与能量守恒**（conservation_law）：处理球—鼓完全弹性碰撞。；证据页：5, 6。
- **欧拉刚体旋转定理**（rigid_body_rotation）：将倾斜鼓面分解为平动和绕轴转动。；证据页：7, 8, 9。
- **转动惯量与力矩模型**（moment_model）：计算队员拉力对鼓面角运动的影响。；证据页：9, 10, 11。
- **模拟退火多目标优化**（simulated_annealing）：同时优化拉力大小、发力时机和鼓面倾角。；证据页：20, 21, 22。

## 论文报告的主要结果

- 给出九类拉力组合对应的鼓面倾角。
- 将小角度转动拆分为两个自由度的独立旋转。
- 通过全局优化得到适用于不同倾斜情形的队员调整方案。
