# 模型与算法摘要

## 总体方法

构造折扣力度指标，使用两类成本补全方案、迭代加权最小二乘和价格弹性分析，研究折扣与营业额及利润率的关系。

## 模型与算法

- **数据汇总与缺失处理**（preprocessing）：汇总、拼接、排序并删除缺失或异常记录。；证据页：3, 4。
- **两类成本补全**（cost_imputation）：按商品历史或随机利润率补全缺失成本。；证据页：4, 5。
- **折扣力度指标**（feature_engineering）：融合促销时间、价格和数量构造粗粒度折扣强度。；证据页：6, 7。
- **迭代加权最小二乘**（robust_regression）：拟合折扣力度与营业额、利润率。；证据页：8, 9, 10。
- **需求价格弹性**（elasticity_analysis）：比较不同商品类别的价格敏感性。；证据页：13, 14, 15。

## 论文报告的主要结果

- 折扣力度与销售额呈正相关。
- 折扣力度与利润率呈负相关。
- 价格弹性高的类别对折扣反应更明显。
