# 模型与算法摘要

## 总体方法

用 Excel 计算营业额、利润率和折扣力度，建立线性回归与类别模型，分析各类商品折扣策略。

## 模型与算法

- **成本比例线性回归**（regression）：利用有成本记录估计非折扣商品成本。；证据页：4, 5。
- **日级经营指标核算**（financial_aggregation）：计算每日营业额、利润和利润率。；证据页：5, 6, 7。
- **降价百分比等级化**（feature_engineering）：将每日降价百分比映射为折扣力度等级。；证据页：7, 8, 9。
- **Excel 统计与数据拟合**（regression）：拟合折扣力度、销售额和利润率。；证据页：9, 10, 13。
- **28 类商品分组分析**（category_analysis）：按商品大类比较销量和利润反应。；证据页：11, 12, 13。

## 论文报告的主要结果

- 论文报告在折扣力度约 5.5、降价约 15.5% 时利润率达到约 19.4%。
- 弹性较高商品对折扣更敏感；部分非必需品利润改善有限。
