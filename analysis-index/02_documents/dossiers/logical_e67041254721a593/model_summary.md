# 模型与算法摘要

## 总体方法

基于排队论、收益成本比较和需求预测建立司机选择模型，并设计多上车点及短途出租车优先排队方案。

## 模型与算法

- **生灭过程排队模型**（queueing_model）：估计蓄车池等待时间和队列变化。；证据页：5, 8, 14。
- **乘客到达量预测**（forecasting）：基于航班与交通数据插值预测出租车需求。；证据页：11, 12, 13。
- **净收益决策模型**（decision_model）：比较排队载客与空载返城的单位时间收益。；证据页：9, 10, 14。
- **灵敏度与噪声分析**（sensitivity_analysis）：改变需求、时间和成本参数检验决策稳定性。；证据页：16, 17, 18。
- **蒙特卡洛上车点模拟**（monte_carlo）：模拟多上车点布局的乘车效率。；证据页：21, 22, 23。
- **优先排队模型**（priority_queue）：依据短途里程和收益差确定重新入队位置。；证据页：24, 25, 26。

## 论文报告的主要结果

- 示例日 12:24—15:00 倾向空载返城，其他时段倾向排队载客。
- 15:00 蓄车池约 806 辆，预计排队 1.6 h，收益约 54.3 元/h。
- 报告决策准确率约 88.46%。
- 多上车点方案给出 5 个上车点、10 个泊位、发车效率约 184 辆/h。
