# 模型与算法摘要

## 总体方法

建立同心鼓平动、转动和球—鼓碰撞的系统动力学模型，以队员总用力最小和颠球高度约束为目标搜索最佳协作策略，并研究倾斜纠偏。

## 模型与算法

- **系统受力分析**（mechanics）：统一描述鼓、排球、拉绳与队员拉力。；证据页：4, 5, 6。
- **二阶微分方程**（ode_model）：建立鼓与球在碰撞前、中、后的运动方程。；证据页：6, 7, 8。
- **时间离散化**（time_discretization）：逐小时间步更新速度、位置与碰撞状态。；证据页：9, 10, 11。
- **四元数姿态描述**（quaternion）：描述鼓面法向量和倾斜状态，避免欧拉角奇异。；证据页：14, 15, 16。
- **最优还原模型**（optimization）：在少量队员调整和拉力变化约束下恢复鼓面姿态。；证据页：24, 25, 26。

## 论文报告的主要结果

- 均匀 80 N 发力、约 0.01 s 时机的策略在给定约束下表现较好。
- 理想模型报告颠球高度约 0.4116 m。
- 针对实测倾斜，调整后倾角和颠球高度得到改善。
