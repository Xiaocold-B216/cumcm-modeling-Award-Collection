# 模型与算法摘要

## 总体方法

从燃油密度、压力与流量关系出发建立高压共轨系统离散模型，分别优化单向阀、柱塞泵、双喷嘴和减压阀控制。

## 模型与算法

- **最小二乘物性拟合**（least_squares）：拟合压力与密度/弹性模量关系。；证据页：4, 5。
- **质量守恒微分模型**（mechanistic_ode）：描述油管、柱塞腔及喷嘴流量变化。；证据页：5, 6, 15。
- **离散时间遍历求解**（search_optimization）：离散化后遍历控制变量寻找最优值。；证据页：8, 18, 21。
- **双喷嘴相位优化**（phase_optimization）：优化两喷嘴启动时间差和凸轮角速度。；证据页：20, 21。
- **阈值减压控制**（control_model）：比较压强阈值开启与周期性减压阀方案。；证据页：22, 23。
- **扰动稳定性检验**（robustness_analysis）：对控制模型加入随机扰动检验抗干扰性。；证据页：24, 25。

## 论文报告的主要结果

- 单向阀最优开启时长约 0.29 ms。
- 2 s、5 s、10 s 升压情形给出约 0.90、0.75、0.73 ms 的过渡控制参数。
- 凸轮角速度约 27.195 rad/s 时压力波动较小。
- 双喷嘴半周期错峰方案与阈值减压方案均被比较。
