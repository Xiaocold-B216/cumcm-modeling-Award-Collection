# 模型与算法摘要

## 总体方法

通过探索性分析、时间对齐、关联度与多元线性回归识别差异因素，再以分段线性插值将国控点校准信息扩展到自建点高频数据。

## 模型与算法

- **探索性数据分析**（eda）：检查连续性、分布、分位数、相关性和 24 小时变化。；证据页：4, 5, 6, 7。
- **时间对齐差异计算**（temporal_alignment）：将国控点和自建点按时间段聚合后计算差值。；证据页：8, 9。
- **关联度分析**（correlation_analysis）：寻找污染物差值与气象变量的主要关联因素。；证据页：10, 11, 12。
- **多元线性回归**（multiple_regression）：对每类污染物建立差值影响模型。；证据页：15, 16, 17。
- **分段线性插值校准**（piecewise_interpolation）：把较低频国控点校准信息插值到自建点高频序列。；证据页：19, 20, 21。

## 论文报告的主要结果

- 识别国控点与自建点在分布、连续性及日内峰谷上的差异。
- 不同污染物的主要差异影响因素不同。
- 论文报告校准残差由 56717 降为 1649，约为原残差的 2.9%。
