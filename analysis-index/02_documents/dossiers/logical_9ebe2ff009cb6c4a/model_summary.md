# 模型与算法摘要

## 总体方法

以压力波动最小为目标，建立高压油管质量守恒微分模型，并将阀门、凸轮、针阀和双喷嘴工作过程统一到数值模拟与优化框架中。

## 模型与算法

- **质量守恒常微分方程**（mechanistic_ode）：依据进出油质量差建立管内密度和压力动态方程。；证据页：4, 5, 6。
- **压力—密度数值积分**（numerical_integration）：由弹性模量与压力关系数值积分获得燃油密度函数。；证据页：6, 7。
- **差分离散与数值模拟**（finite_difference）：将连续动态方程改写为离散递推式，逐时间步模拟压力变化。；证据页：8, 9, 18。
- **积分平方偏差目标规划**（optimization）：以目标压力与模拟压力的积分平方偏差为目标函数。；证据页：8, 14, 18。
- **遍历与分层搜索**（search_optimization）：搜索单向阀开启时长、凸轮角速度、喷嘴间隔和减压阀参数。；证据页：10, 19, 21, 24。
- **凸轮—针阀几何模型**（geometry_model）：由凸轮轮廓和针阀运动计算有效流通面积。；证据页：15, 16, 17。

## 论文报告的主要结果

- 100 MPa 稳压时单向阀开启时长约 0.288 ms。
- 升至 150 MPa 后稳态开启时长约 0.752 ms。
- 柱塞泵模型给出凸轮角速度约 27.5 rad/s；双喷嘴方案给出 55 rad/s 与 50 ms 间隔的组合。
- 比较泄压阀式和电磁阀式减压控制方案。
