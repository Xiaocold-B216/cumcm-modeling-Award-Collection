# 模型与算法摘要

## 总体方法

以管内压力波动最小为目标，采用压力—密度拟合、有限差分和多重搜索优化单向阀、凸轮、双喷嘴及减压阀参数。

## 模型与算法

- **压力—密度曲线拟合**（curve_fitting）：拟合弹性模量、压力与密度关系。；证据页：4, 5。
- **有限差分压力模型**（finite_difference）：离散质量守恒方程计算管内压力。；证据页：5, 6, 7。
- **目标规划模型**（optimization）：最小化相对目标压力的波动或偏差。；证据页：7, 18, 22。
- **多重搜索算法**（search_optimization）：以逐步缩小步长的方式搜索阀门时长、凸轮速度和喷射时差。；证据页：8, 19, 23。
- **凸轮边缘与针阀几何**（geometry_model）：由轮廓曲线、针阀间隙与面积计算流量。；证据页：11, 12, 13。
- **灰色/样条辅助处理**（interpolation）：对轮廓和物性离散数据进行插值。；证据页：12, 13。

## 论文报告的主要结果

- 稳压 100 MPa 时单向阀开启时长约 0.2875 ms。
- 压力升至 150 MPa 后开启时长约 0.765 ms。
- 柱塞泵搜索得到凸轮角速度约 27.3 rad/s。
- 双喷嘴最优开始间隔约 49.1 ms；阈值减压方案报告阈值约 102.25 MPa。
