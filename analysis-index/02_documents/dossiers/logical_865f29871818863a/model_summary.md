# 模型与算法摘要

## 总体方法

从分布、相关性、零点漂移、量程漂移、交叉影响和气象因素出发建立回归校准模型，对自建点高频序列进行修正。

## 模型与算法

- **数据质量与缺失处理**（preprocessing）：检查数据范围、缺失时段和异常值。；证据页：3, 4。
- **分布与箱线图分析**（eda）：比较六类污染物的分布和异常点。；证据页：5, 6, 7。
- **相关矩阵与散点矩阵**（correlation_analysis）：比较国控点、自建点及气象变量的关系。；证据页：6, 8, 9。
- **零点漂移和量程漂移**（sensor_drift_analysis）：按小时均值和日标准差刻画传感器漂移。；证据页：10, 11, 12。
- **交叉影响回归**（regression）：分析污染物之间以及天气变量对误差的影响。；证据页：13, 14, 15。
- **归一化回归校准**（calibration_model）：依据国控数据的零点和量程修正自建点。；证据页：18, 19, 20。

## 论文报告的主要结果

- 识别 PM2.5 与 PM10 的高相关关系以及 O3 与其他指标较弱的相关性。
- 指出不同污染物的漂移与气象影响路径不同。
- 校准后绝对误差和相对误差均明显降低。
