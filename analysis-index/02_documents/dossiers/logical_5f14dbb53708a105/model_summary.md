# 模型与算法摘要

## 总体方法

将排球—鼓面过程分为下落、碰撞、离鼓等阶段，建立一维碰撞与三维平动/转动模型，给出理想同步发力和误差纠偏策略。

## 模型与算法

- **分段一维碰撞模型**（piecewise_dynamics）：按自由落体、碰撞和离鼓阶段建立动力学方程。；证据页：3, 4, 5。
- **牛顿第二定律**（mechanics）：由合力和加速度求发力时机与排球高度。；证据页：4, 5, 6。
- **三维平动与转动模型**（rigid_body_dynamics）：用平动速度、角速度和角加速度描述鼓面误差。；证据页：7, 8, 9。
- **力矩平衡与转动惯量**（moment_model）：分析不同队员拉力对鼓面转动的影响。；证据页：8, 9, 10。
- **数值计算与策略搜索**（numerical_simulation）：计算不同拉力误差组合并寻找恢复竖直方向的方案。；证据页：10, 11, 12。

## 论文报告的主要结果

- 理想情形给出约 90 N 的同步拉力与 0.194 s 开始发力时刻。
- 较易操作的方案给出约 80 N 拉力和 0.22 s 开始发力。
- 对鼓面倾斜情形给出一组非均匀拉力用于纠偏。
