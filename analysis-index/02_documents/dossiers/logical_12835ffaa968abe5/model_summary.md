# 模型与算法摘要

## 总体方法

从司机和机场两侧建模：用 0-1 决策比较排队与返城，用队列模拟划分时段，再以交通流模型和短途标准设计管理方案。

## 模型与算法

- **0-1 收益决策**（binary_decision）：以最大利润为目标选择排队或返城。；证据页：5, 8, 9。
- **队列模拟与曲线拟合**（queue_simulation）：拟合乘客流量、出租车流量和等待时间。；证据页：10, 11, 12。
- **控制变量敏感性分析**（sensitivity_analysis）：分析等待收益、返城收入和油耗影响。；证据页：13, 14。
- **交通流上车点优化**（traffic_flow_optimization）：以乘车效率为目标确定泊车位数量。；证据页：20, 21, 22。
- **短途优先临界模型**（priority_rule）：按时间或里程收益平衡确定短途车优先权。；证据页：24, 25, 26。

## 论文报告的主要结果

- 示例机场被划分为四个司机决策时段。
- 模型认为等待时间是排队收益的主要影响因素。
- 上车点泊车位数量以乘车效率最大化确定。
- 给出基于时间和基于路程的两种短途优先标准。
