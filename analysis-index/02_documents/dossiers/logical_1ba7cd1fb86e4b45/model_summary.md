# 模型与算法摘要

## 总体方法

综合灰关联分析、样条插值、加权平均、RBF 神经网络和逐步多元线性回归建立自建站数据校准模型。

## 模型与算法

- **SPSS 描述统计与 BDP 图**（eda）：分析污染物分布、峰度和日内变化。；证据页：4, 5, 6, 7。
- **数据清洗与标准化**（preprocessing）：删除异常/重复记录并进行三次样条插值和标准化。；证据页：8, 9, 10。
- **灰色关联分析**（grey_relational_analysis）：衡量气象因素与污染物误差的关联程度。；证据页：11, 12, 13。
- **加权平均校准**（weighted_average）：融合国控点估计值与自建点观测值。；证据页：20, 21。
- **RBF 神经网络**（rbf_network）：预测测量误差并修正自建点数据。；证据页：23, 24, 25。
- **逐步多元线性回归**（stepwise_regression）：筛选影响变量并建立校准方程。；证据页：28, 29, 30。

## 论文报告的主要结果

- 指出风速与多项污染物误差存在较高灰关联度。
- 比较加权平均、RBF 网络和逐步回归的校准结果。
- 给出各污染物的误差修正序列。
