# 模型与算法摘要

## 总体方法

清洗销售流水并补齐成本，计算日营业额、利润率和折扣率，利用回归和分段拟合分析折扣对销售与利润的影响，再进行商品类别比较。

## 模型与算法

- **销售流水清洗**（preprocessing）：剔除无效订单并处理成本缺失。；证据页：3, 4。
- **营业额与利润率核算**（financial_aggregation）：按日汇总销售额、成本和利润率。；证据页：5, 6。
- **折扣率与折扣力度构造**（feature_engineering）：由原价与售价计算折扣率并形成日级指标。；证据页：7, 8。
- **线性与分段回归**（regression）：拟合折扣力度与销售额、利润率的关系。；证据页：8, 9, 10。
- **商品类别对比**（category_analysis）：将商品分组比较策略适用性。；证据页：12, 13, 14。

## 论文报告的主要结果

- 销售额总体随折扣力度增加而上升，但论文认为影响不强。
- 利润率随折扣力度增加而下降。
- 食品、进口类和日用类被认为更适合分析“薄利多销”。
