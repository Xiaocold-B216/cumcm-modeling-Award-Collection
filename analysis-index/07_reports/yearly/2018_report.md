## 3. 关键纠错

1. `2018A：基于多原则比较和蒙特卡洛模拟的 RGV 动态调度模型.pdf` 的文件名前缀写为 A，但全文研究对象、题面参数、三类情景和结果均为 B 题，已按内容归入 B 题，原文件名和哈希保持不变。
2. A 题附件工作簿不是“一个附件对象”：`附件1` 为材料参数，`附件2` 为 0—5400 s 温度序列；建立两个 logical documents，共用一个物理载体并通过 sheet region 区分。
3. B 题附件 2 的 RAR 不是一篇文档：RAR 是容器载体，内部 4 个 XLS 分别是 Case 1、Case 2、Case 3 单工序故障、Case 3 双工序故障输出模板。
4. C 题的 TXT 只是下载说明，不是题面所称 5 份数据附件，不能把它当作完整 C 题数据集。
5. 《大型百货商场会员画像描述》称激活率与销量“强线性相关”，但同时给出含二次项的拟合式；知识库记录为“相关系数 0.83，采用二次拟合”，不将二次式误标为线性模型。
6. 《基于非稳态导热的高温作业专用服装设计》摘要中的 3327 s 与“超温不超过 300 s”表述有语义歧义。结合 3600 s 总时长，3327 s 更合理地解释为达到 44℃附近的时刻，对应约 273 s 超温时间；保留原文结果并标注歧义，不擅自改写数值。
7. 三篇 A 题、四篇 B 题、三篇 C 题和三篇 D 题均按哈希、页数、模型结构与求解策略核验为独立 solution lineage。

## 4. 模型与算法谱系

### A 题：多层非稳态传热 → 数值 PDE → 参数反演 → 厚度优化

共同骨架是 Fourier/能量守恒建立一维多层热传导方程，使用边界换热和界面连续条件，再以有限差分求解。三篇论文分别强调：最小二乘与辐射扩展；隐式差分和追赶法；后向欧拉、边界参数反演、黄金分割及二维可行域搜索。厚度结果存在差异，表明边界条件、目标定义和数值步长对最优解敏感。

### B 题：离散事件调度 → 规则/前瞻/状态图 → 布局优化 → 随机故障

- 0-1 规划与启发式：显式刻画路径、上下料、工序与 8 小时约束。
- 有限步前瞻：以“八步一走”和多步捆绑减少 CNC 等待。
- 多规则比较：就近、FIFO、HRRN，并遍历 256 种工序布局。
- 状态图：用状态向量、转移矩阵、多阶段决策和剪枝求解。
- 故障层：1% 故障概率、均匀故障时刻/维修时长、Monte Carlo 与方差分析。

四篇论文在单工序结果上集中于约 382—393 件，在双工序结果上集中于约 209—253 件，差异主要来自刀具布局、前瞻深度、理想上界定义及调度规则。

### C 题：数据清洗 → 会员价值 → 生命周期 → 激活 → 连带营销

- 价值层：K-means 购买力分群、FMS/RFMS、AHP 加权 RFMT。
- 状态层：规则型生命周期、滑动时间窗 RF、K-means 生命周期、Markov 转移。
- 激活层：月度状态转移、队列激活率、因子分析、促销相关/回归。
- 连带层：FP-Growth、关联规则、商品交叉连带率与热门品类。

由于 C 题附件 1—5 未上传，这些数值结论只能作为论文中已报告结果，不能提升为本轮独立复算结论。

### D 题：约束序列构造 → 分层启发式/规划 → 图搜索 → 成本校验

- 优化与图搜索路线：人工预排黑色块，使用 0-1 规划处理四驱和柴油间隔，再把剩余复杂颜色转化为有向图，以遗传算法 TSP、BFS 和路径代价评价选择顺序。
- 分层构造路线：依次固定品牌、喷涂奇偶位、颜色、驱动、动力和配置，以黑色车辆为骨架并对稀缺颜色作规则插入。
- 序贯多目标路线：按属性优先级拆分子目标，设计五步确色法、黑车最小组数和驱动/动力批次间隔公式，并以 C 程序生成排程。

三篇论文均生成 9 月 17—23 日每日 460 辆装配顺序，但最优性层级不同：第一篇组合数学规划与路径枚举，另外两篇更依赖启发式规则和人工微调。
