## 模型与算法谱系

### A题：CT标定与图像重建

五篇论文形成五条独立路线：

- 解析投影强度 + 形态学分离 + 最小二乘 + 逆Radon；
- 简化离散几何 + R-L滤波反投影 + 镶边平移 + 自适应降噪；
- 全局非线性最小二乘迭代 + FBP/ART双重重建 + 分布检验；
- 小圆投影不等式 + 微元运动方程 + Prewitt边缘 + FBP；
- 黄金分割 + 单目标误差优化 + 遍历搜索 + FBP。

高度一致的核心数值是探测器间距约0.2768 mm；旋转中心估计集中在约(-9.3, 5.6-6.3) mm，但不同论文因坐标、近似与优化策略产生差异。

### B题：众包任务定价

收到的一篇论文采用任务/会员密度、相关分析、吸引力因子、任务分配仿真、K-means打包与搭售边界。它将完成率、会员收入和平台收益共同作为评价指标，而不是只优化价格拟合。

### C题与D题

题面和数据已完整入库，但对应论文载体未上传，因此不从题面或数据臆造论文模型谱系。C题只记录可选问题结构（回归/降维/颜色空间/误差分析），D题只记录可选问题结构（图上周期任务、车辆路径/排班、休息约束），状态均为待论文证据补齐。
