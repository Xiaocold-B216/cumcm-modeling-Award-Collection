## 四、模型与算法谱系

### A 题：波浪能动力学与阻尼优化

- A001：牛顿第二定律 -> 二自由度 ODE -> RK4 -> 梯形功率积分 -> 遗传算法阻尼搜索 -> 垂荡/纵摇联合优化。
- A171：拉普拉斯解析解 + RK4 数值解 -> 力电比拟/阻抗匹配 -> 梯形积分 -> 直线与旋转阻尼联合优化。

### B 题：纯方位定位与编队调整

- B030：圆周几何分类 -> 遍历定位 -> 仿真坐标验证 -> 分步迭代调整。
- B035：正弦/余弦方程与圆轨迹求交 -> 误差传播 -> L2 loss -> 带阈值启发式搜索 -> 连续信号帧纠错。
- B086：极坐标定位与到达次序消歧 -> 正多边形编号推断 -> 局部最优/贪心调整 -> 三维质心与平面拟合。

### C 题：组成数据统计学习

乘法替换/闭合 -> Spearman 与卡方 -> Dirichlet 回归 -> clr 变换 -> 决策树 -> PLS-DA/VIP -> 聚类 -> Pearson/Wilcoxon 相关结构比较。

### E 题：需求预测与库存排产

多指标物料筛选 -> 三次指数平滑 -> 100 周滚动预测 -> 库存流量平衡 -> 强化参数/联合调整 -> 库存与服务水平情景比较。
