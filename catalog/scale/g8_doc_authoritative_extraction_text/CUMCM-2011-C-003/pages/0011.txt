问题 2 问题二是求养老金替代率，养老金替代率是指劳动者退休时的养老金领 取水平与退休前工资收入水平之间的比率。它是衡量劳动者退休前后生活保 障水平差异的基本指标之一。影响养老金替代率的因素有：社会平均工资； 个人在职时的工资收入和企业缴费工资总额；工作年限和缴费年限；退休年 龄等等。养老金替代率的具体数值，通常是以“某年度新退休人员的平均养 老金”除以“同一年度，在职职工的平均工资收入”来获得，所以我们必须 先计算出新退休人员的平均养老金和在职职工的平均工资收入，然后再根据 养老金的计算办法计算养老金继而算出替代率。 首先，根据附件 2，为了方便计算我们把其月收入范围取了一个平均值， 如表 2.1 表 2.1 各年龄段工资 月收入（元） 年龄段 1250 1750 2250 2750 3250 3750 4500 6500 20-24 74 165 26 16 1 0 0 0 25-29 36 82 94 42 6 3 0 0 30-34 0 32 83 95 24 6 2 0 35-39 0 11 74 83 36 16 4 2 40-44 0 0 43 86 55 21 13 3 45-49 0 3 32 32 64 41 18 4 50-54 0 7 23 29 44 21 8 3 55-59 0 6 17 27 37 7 7 0 然后，又表 2.1 我们算出：企业总平均工资=2580.23，由此可算出表 2.2 表 2.2 各年龄段平均收入、缴费指数 年龄段 平均收入 缴费指数 20-24 岁职工数 1726.95 0.6693 25-29 岁职工数 2077 0.805 30-34 岁职工数 2535.12 0.9825 11 [Image: Image6]
