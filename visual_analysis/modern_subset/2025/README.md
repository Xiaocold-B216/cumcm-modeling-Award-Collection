> Created: 2026-09-03

## Purpose

This subset provides visual and argument analysis of recent CUMCM award papers,
complementing the historical format audit. It captures:

1. **Paper Visual Profile** (`paper_style_profile.json`)
   - Page structure, content density, layout, visual style

2. **Argument Profile** (`argument_profile.json`)
   - How the paper tells its "story"
   - Section sequence, argument placement patterns
   - Writing strategy

## Eligibility

This subset is NOT gated by G8 method-evidence eligibility.
Only requirements:
- Confirmed award paper (not problem statement)
- Source exists
